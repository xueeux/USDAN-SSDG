# USDAN-SSDG
## Acknowledgements and Upstream References

USDAN-SSDG is my graduation thesis project on semi-supervised face anti-spoofing. It builds on SSDG and draws on USDAN for unsupervised and semi-supervised domain adaptation.

### SSDG

Yunpei Jia, Jie Zhang, Shiguang Shan, and Xilin Chen.  
“Single-Side Domain Generalization for Face Anti-Spoofing.”  
CVPR, 2020.

Original repository:  
https://github.com/taylover-pei/SSDG-CVPR2020

### USDAN

Yunpei Jia, Jie Zhang, Shiguang Shan, and Xilin Chen.  
“Unified Unsupervised and Semi-supervised Domain Adaptation Network for Cross-scenario Face Anti-spoofing.”  
Pattern Recognition, 2021.

Original repository:  
https://github.com/taylover-pei/USDAN-PR

### Thesis Contributions

My thesis investigates the integration and extension of these approaches using labelled and unlabelled target-domain data, patch-shuffling consistency, and joint optimisation. My contributions include method integration, implementation changes, comparative and ablation experiments, feature visualisation, and thesis writing.

The original methods and upstream implementations are credited to their respective authors. Reported performance figures refer to the experimental setting documented in my thesis.
